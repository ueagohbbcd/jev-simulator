# 概率、温度和诊断

默认 `token_logprobs` 模式每次调用读取首输出位置的 logprob，转换成原始概率。标签按字符串精确匹配，大小写与前导空格均参与匹配；最终答案由目标标签分布计算。

## 直接报告概率

`reported_probability` 读取完整 JSON 对象，键为本场标签，值为 [0,1] 内的有限数。必须包含全部标签且无额外或重复键；拒绝布尔值、截断、拒答和非法 JSON。总和须在 1 的 1e-6 容差内，仅归一化浮点微小偏差。校验失败返回错误，不补零、不自动重试。

原始内容及报告分布保留在完整诊断中。之后按 `p_i^(1/T)` 归一化，零概率保持零；双循环再执行下文的聚合。原始数值报告没有 token 质量，不能与 logprobs 的质量诊断混用。两种模式共享外部答案结构，效果需要各自评估。

## 读取与质量界（logprobs）

令 O 为已观察到的去重 token 集合，A 为目标标签集合。采样 token 若有有效概率，也加入 O；它不一定在 top-k 中。无效数值及 -9999 哨兵不作为概率使用。

目标质量下界 `L = sum(exp(lp[t]) for t in A ∩ O)`。剩余概率 `R = max(0, 1 - sum(exp(lp[t]) for t in O))`。缺失目标数为 m；若有效 top-k 列表末位概率为 c，则：

```text
U = L + min(R, m × c)
```

top-k 截止值不可靠时仅用剩余质量作保守上界。目标全部出现时 U=L。界限基于供应商返回的概率精度和 top-k 排名约定，浮点舍入可能产生极小误差。

概率质量衡量输出落在目标标签上的概率，用于检查输出格式。答案准确率需用标注数据评估。高质量与缺失标签可以同时出现，例如一个标签占 99.9%，其余目标标签落在 top-k 之外。

## 温度缩放（logprobs）

已观察目标使用 logprob，缺失目标按负无穷（概率 0）处理，然后：

```text
p_i(T) = exp((lp_i - max(lp)) / T) / sum_j exp((lp_j - max(lp)) / T)
```

T=1 是原始目标内归一化；T>1 变平，0<T<1 变尖。正温度保持单次候选排序，同时调整 Noul 数值、Score 期望和集中度 confidence。二分类 T=3 时，99%、99.9%、99.99% 分别变成约 82.23%、90.91%、95.56%。多分类对全部候选概率一起变换，再归一化。

温度在每次请求归一化时应用一次，双循环随后聚合。原始质量上下界在温度之前计算；logprobs 模式的上游采样 temperature 固定为 1。

缺失目标按 0 参与计算，缩放后仍为 0。升温会增加尾部概率的相对权重，也可能放大补零近似的误差。温度异于 1 且存在缺失时会单独告警。

默认 T=1。校准时应固定模型与提示词，用独立标注数据选择温度，并在留出的样本上评估 NLL、ECE 等指标。

## 双循环

每对候选进行两个方向的调用。把各场结果映射回语义键，对两个方向取概率均值。每个候选的胜分为对所有对手的期望获胜概率之和，再除以全体候选的胜分总和，得到最终分布。Score 对这个分布取等级期望。

双循环分布表达候选之间的相对胜分，使用时应单独校准置信阈值。例如三个候选的胜分为 2、1、0，归一化后第一名为 2/3。Noul 始终执行一次 Yes/No 判断。

## 告警和数据出口

兼容端点只返回标准答案字段；扩展端点另含配置元数据和告警。结构化 stderr 日志提供请求 ID、配置 ID、读取模式和告警，logprobs 模式另含每次调用的概率质量与缺失数量。CLI 的 `evaluate --diagnostics PATH` 额外保存完整证据，包括实际提示词、映射、原始标签 logprobs、温度前后分布和 top token；默认不落盘。

以下告警针对 logprobs 模式：

| 条件 | 含义 |
| --- | --- |
| 目标未全部出现 | 完整返回分布中包含补零近似 |
| U 小于质量门槛 | 可以确认目标质量过低 |
| L 小于门槛但 U 不低于门槛 | 质量区间跨越门槛，记录不确定性告警 |
| 非目标 token 居首或并列第一 | 输出协议偏离，目标内分布仍返回并明确告警 |
| 缺目标且 T 不为 1 | 升温／降温在不完整数据上计算 |

质量门槛默认 0.99。告警随计算结果一同输出；目标全缺失时返回错误。重试由调用方决定。

单次 Choice/Score 可直接对标准 probabilities 再做温度变换：已有温度 T 改到 T'，相当于对当前分布取 T/T' 次幂再归一化。单次 Noul 可用 p 和 1-p 还原二分类条件分布。

分析归一化前质量、区分缺失与低概率标签，或重新计算双循环各场温度时，应保存完整诊断，其中包含这些操作所需的原始观测。
